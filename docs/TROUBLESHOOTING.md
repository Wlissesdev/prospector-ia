# Solução de problemas

| Sintoma | Ação |
| --- | --- |
| `py` não encontrado | Instale Python 3.12 e marque o Python Launcher. |
| Script bloqueado | Execute `Set-ExecutionPolicy -Scope Process Bypass` na janela atual e repita. |
| Porta ocupada | Execute Streamlit com `--server.port 8502`. |
| CSV inválido | Confira cabeçalho, mapeie usuário ou URL e baixe o relatório de erros. |
| Modelo sem dados | Registre ao menos 3 aprovações e 3 rejeições, 8 decisões no total. |
| URL não verificável | O destino pode ser privado, local, bloqueado, lento ou exigir login. O sistema não contorna bloqueios. |
| Integração sem permissão | Use o fluxo assistido até possuir permissões oficiais verificadas. |
| OCR não disponível | OCR é opcional. Digite ou cole o texto visível da captura. |
| Banco com erro | Crie uma cópia dos arquivos de dados e use a restauração pela tela Configurações. |
