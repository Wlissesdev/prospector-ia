# Roadmap

## Implementado na versão 1.0

- CRM local, importação/exportação, evidências, relações por semente, regras, revisão, mensagens assistidas, ML local, relatórios, backup e diagnóstico.

## Condicionado a permissões externas

- Conector Instagram Graph API com endpoints e escopos confirmados; atualmente o aplicativo informa configuração, mas não declara conectividade nem suporte a dados indisponíveis.

## Futuro

- OCR local opcional; visualização de grafo; detecção de mudanças; métricas de resposta; conectores autorizados adicionais; instalador Windows; PostgreSQL para uso multiusuário.
