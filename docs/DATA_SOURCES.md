# Fontes de dados e proveniência

Ordem recomendada: integração oficial autorizada, dados importados pelo usuário, entrada assistida, captura fornecida pelo usuário e outras fontes somente quando avaliadas e configuradas.

Cada evidência armazena o tipo, origem, data de captura, texto bruto ou extraído, estado de verificação, confiança, notas e arquivo local quando aplicável. A análise de URL também registra URL original, destino final, cadeia de redirecionamento, domínio, categoria e erro.

O sistema não visita URLs durante a importação. A resolução acontece somente por ação explícita na tela e bloqueia esquemas que não sejam HTTP(S), hosts locais, privados, link-local, reservados e multicast.
